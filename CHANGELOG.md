# Changelog

## 0.1.0

Initial E.ON Hungary support: UI setup and address reconfiguration, planned
outage matching and calendar, area fault reports, daily polling, manual refresh,
shared downloads, independent feed health, redacted diagnostics and Hungarian /
English translations. Other operators are not yet supported.

- Optional local radius matching, fault area overlap, nearby sensors and calendar.
- Optional parcel number (HRSZ) input and exact town-scoped parcel matching.
- Town matching includes published districts/localities; Budapest district numbers accept Roman and Arabic forms.
